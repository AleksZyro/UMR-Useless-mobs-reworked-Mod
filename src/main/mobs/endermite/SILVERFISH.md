# Corrupted Silverfish

This is part of the MySith dark-side module. It contains the Corrupted Silverfish rework:

- hidden corrupted host blocks
- Corrupted Silverfish combat and drops
- Resonator, flare, dust bomb, bait, and crystal leggings

Shared registration still happens in the main mod class so the whole project builds as one Forge mod.
The gameplay fantasy is dark, hidden, cave-corrupted, and grindy-but-trackable.
