# Mob Module Layout

Each folder here can work like a small feature module inside the one shared Forge mod.

- `endermite`: Dark-side gameplay: Endermite/MySith plus corrupted silverfish content.
- `slime`: Light-side gameplay: royal slimes, golden/blue slime gear, and heroic rewards.

Shared Forge setup, common registries, common config, and cross-mob files stay outside in
`src/main/java`, `src/main/resources`, or `src/main/common`.
